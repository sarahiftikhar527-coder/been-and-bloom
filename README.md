# ☕ Been & Bloom

Been & Bloom is a modern, elegant, and responsive coffee shop website designed to create a warm and premium digital café experience.

The website combines a sophisticated coffee-inspired design with smooth animations, responsive layouts, interactive sections, and an easy-to-use contact experience.

## ✨ Features

- Modern and elegant coffee shop UI
- Fully responsive design
- Animated sections using Framer Motion
- Responsive navigation
- Hero sections with smooth animations
- Coffee menu/product sections
- Customer testimonials
- Store/location section
- Google Maps integration
- Contact form
- Contact information section
- Business hours section
- Call and email actions
- Interactive hover effects
- Smooth page transitions
- Mobile-friendly layout
- Reusable React components

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- Tailwind CSS
- Framer Motion
- React Icons
- Google Maps Embed
